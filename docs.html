这个看板在算什么

把分散在多家券商、多个币种、两个人名下的资产和负债，折算成同一套口径的「家庭资产负债表」；再把期权持仓折成 Delta 敞口和保证金占用，用来回答两个问题：钱在哪里、风险有多大。

数据来源：飞书表（手填与公式）＋ IBKR 交易接口（实时持仓、保证金）＋ 公开汇率接口。后端 Python，前端单页 HTML，Claude Code 协作完成。

家庭资产：内部往来双向冲销

我视角里「家庭内部往来」是负债，家人视角里「配偶-代管／借款」是资产，是同一笔钱。家庭口径把它们双向去掉，只留对外的资产和负债。

我视角家人视角家庭口径
家庭内部往来（代管）＝负债配偶-代管＝资产互相抵消
家庭内部往来（港币／人民币）＝负债配偶-港币／人民币借款＝资产互相抵消

家庭总资产 = 我的对外资产 + 家人对外资产　家庭净资产 = 我的净资产 + 家人净资产

「代管」一项自动等于家人名下所有账户折港币的合计，两边永远精确相等，不需要手动同步。

持仓 Delta 与保证金：两种问法，两个答案

列回答的问题怎么算
独立占用这个仓单独持有、不考虑对冲时占多少保证金Reg-T 公式：裸卖 call ＝（期权价 ＋ max(20%×现价 − 价外额, 10%×现价)）× 乘数 × 张数；价差按行权价差；正股多头 25%、空头 30%
平仓可释放把这个标的全部平掉，账户实际腾出多少IBKR whatIf 模拟平仓（纯模拟不下单）；多腿用组合单一次平

两者的差就是「组合保证金省下的」和「对冲仓共用、单平任一边都释放不了的」部分。饼图按大类拆账户实际维持保证金，加总正好等于账户实际值。

Delta 用 IBKR 实时希腊值，收盘拿不到时按 Black-Scholes 本地回算；每个标的再乘 beta 折成「等效纳指敞口」。
